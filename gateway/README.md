# Gateway

## Описание

Gateway — единая точка входа в систему.  
Отвечает за аутентификацию пользователей, проверку прав доступа и маршрутизацию запросов во внутренние сервисы.

---

## Основные возможности

- Аутентификация пользователей (JWT)
- Регистрация пользователей (через user-service)
- Конфигурация через переменные окружения
