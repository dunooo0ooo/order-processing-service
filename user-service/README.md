# User Service

Микросервис управления пользователями и аутентификацией.  
Отвечает за регистрацию пользователей, хранение учётных данных и проверку логина/пароля.

---

## Описание

User Service предоставляет API для:
- регистрации пользователей
- аутентификации (проверки логина и пароля)
- выдачи информации о роли пользователя

---

## Архитектура

- PostgreSQL — хранилище пользователей
- HTTP API — регистрация и логин
- bcrypt — хэширование паролей
- Clean Architecture (delivery / service / repository)

---

## Стек технологий

- Go 1.25
- PostgreSQL
- bcrypt
- Docker / Docker Compose
- Uber Zap (логирование)
