# Order Processing Platform

Демонстрационный проект микросервисной системы обработки заказов.  
Проект показывает базовую production-архитектуру с разделением ответственности, асинхронной обработкой событий и централизованной точкой входа.

---

## Описание

Платформа состоит из нескольких микросервисов, взаимодействующих между собой по HTTP и через Kafka.  
Реализованы хранение заказов, управление пользователями, аутентификация, авторизация и мониторинг.
